## 1. Project state

- **COGS 269** — static feed-forward tonal-space foundation: `ChordToKeyMLP` (24 → 48 → 24) trained on synthetic diatonic triads to predict key from a single chord. No time dimension.
- **COGS 202** — completed prior work: extends the COGS 269 MLP to real MIDI with *hand-coded* temporal smoothing at two levels (chroma-level EMA in `midi_to_chord_ids`, hidden-state leaky integration in `sequence_key_tracking`). No learned temporal component. This milestone is done.
- **Current continuation** — the open question this workspace exists for: compare (and eventually replace) the hand-coded EMA/leaky-memory baseline against a learned recurrent hidden state (Elman SRN), trained end-to-end on labeled chord sequences instead of hard-coded via `alpha`.
