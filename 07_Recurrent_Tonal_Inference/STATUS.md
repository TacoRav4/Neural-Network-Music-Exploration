## 1. Project state

- **COGS 269** — static feed-forward tonal-space foundation: `ChordToKeyMLP` (24 → 48 → 24) trained on synthetic diatonic triads to predict key from a single chord. No time dimension.

## Phase 3B — completed

- `04_Recurrent_Implementation/pitch_class_uncertainty_diagnostics.py` created: computes uncertainty diagnostics for the pitch-class baseline directly from Phase 2C's saved chroma arrays (not by calling `midi_to_key_baseline`, to avoid its leading-silence-drop offset entirely — this module computes over the full, undropped chroma array and tracks silence via an explicit `active` mask, so `prediction_times_sec = idx * window_sec` always, no offset arithmetic needed downstream). - **Two real bugs caught and fixed during development** (both before finalizing outputs): (1) `np.argsort`'s default sort is not tie-consistent with `np.argmax` — since many windows have several `SCALE_TEMPLATES` rows exactly tied (see next finding), the initial argsort-based top-1 selection diverged from `pitch_class_baseline.py`'s canonical `argmax` convention on ~7% of Twinkle 12.mid's windows, concentrated in the validated Eb-major modulation window; fixed by using plain `argmax` for top-1 (matching the canonical baseline exactly) and masking it out before computing top-2. (2) Re-verified this fix against `midi_to_key_baseline`'s own output for the exact real-time range before finalizing.
- **Key structural finding**: `SCALE_TEMPLATES` gives relative major/minor pairs (e.g. C major/A minor) numerically identical rows (same 7 pitch classes), so sparse/monophonic chroma windows frequently tie exactly across many keys (mean ~5.2 tied keys/window for Twinkle.mid, ~6.7 for Twinkle 12.mid, up to 14 simultaneously). This saturates the `low_margin` diagnostic at 100% for both pieces (not a bug — a genuine property of the representation) and makes it non-discriminating on its own; `tie_count` and `key_switch`/`large_jump`/`anchor_mismatch` are the useful criteria instead. Also implies the baseline's real accuracy comes from temporal EMA smoothing accumulating evidence across windows, not from individual windows being decisive — relevant for Phase 3C/3D (a per-window neural classifier alone would face the same ambiguity).
